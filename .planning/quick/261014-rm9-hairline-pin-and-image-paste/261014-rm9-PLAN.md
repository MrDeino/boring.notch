- Closed NotchShape: top radius 6, bottom radius 14 (`cornerRadiusInsets.closed`).
- Fix: hairline bottom = max(drawn shape height, hardware notch height), where hardware notch height = for the notch's screen, `safeAreaInsets.top > 0 ? max(safeAreaInsets.top, frame.maxY - visibleFrame.maxY) : 0` (auto-hidden menu bar gives 0 for the second term -> falls back to safe area). Upload contract (read-only from /Users/mitch/Documents/Claude/orchestrator/orch.js, `chatImage`, lines ~601-625 and route at ~667):
- `POST /api/chat/image` only matched with header `x-orch: 1` (otherwise falls to the /api/chat handler -> 404/400).
- Content-Type must be image/png|jpeg|gif|webp (else 415). Body = raw bytes. Max 10 MB = 10*1024*1024 (`IMAGE_MAX`; Content-Length over it -> 413 + connection close). Empty body -> 400. Success -> 200 `{"path":"<abs path>.png"}` saved under runs/uploads. Errors -> 500 `{"error":...}`.
- So: downscale to max 2000px longest side (pixel dims) before PNG encoding (keeps retina screenshots well under 10 MB); if the PNG is still > 10 MB refuse to attach with a composer tag.
- POST /api/chat text: server collapses newlines; 409 when the chat isn't running.
