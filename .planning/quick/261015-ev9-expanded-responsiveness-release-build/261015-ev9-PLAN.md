What the code does today (read, verified by the planner):
- OrchestratorExpand.installMonitors (only while some vm is expanded): global + local mouseDown monitors each do `Task { @MainActor in self?.collapseIfOutside(refocus:) }`, an extra runloop hop that queues behind any SwiftUI render. collapseIfOutside reads `NSEvent.mouseLocation` (the real cursor), which is why SnapIdle's outsideClick warps the real cursor (CGWarpMouseCursorPosition, SnapIdle.swift ~line 146) and why Snap.swift --hittest (~line 834) cannot click the composer while expanded.
- Open level: no monitor. Close relies on upstream ContentView.handleHover (hover exit -> 100ms Task -> vm.close() unless `SharingStateManager.preventNotchClose`). While the composer/notes/prompt field is typing, OrchestratorManager.beginTyping holds an interaction, so the hover-exit close is refused; the later outside click resigns key -> stopTyping -> endTyping, but nothing re-triggers close, so the notch stays open until the pointer re-enters and leaves. Strong candidate for "closes only after a few seconds".
- vm.close() (BoringViewModel.swift:201) returns early while preventNotchClose is true; collapse() ends the expand interaction first, which is why collapseIfOutside collapses all before closing.
- Observation fan-out: OrchestratorView and OrchestratorExpandedView observe the whole OrchestratorManager (every SSE field) and OrchestratorTranscriptStore; `store.draft` is @Published on the store, so each keystroke re-evaluates OrchestratorExpandedView and OrchestratorChatView bodies (and the transcript ForEach of non-Equatable ChatBlockRow). OrchestratorRunsRail/Strip/Board observe the whole manager; OrchestratorRunCard is not Equatable. apm measured 6.5% (limit 9) for "expanded, doing changes each second" in an unoptimized harness.
- Fade timings: OrchestratorExpanded.swift line 11 `fadeOut = 0.08, fadeInDelay = 0.28, fadeIn = 0.15`; expand spring 0.4/0.82; shrink deferred 650ms (OrchestratorExpand.syncWindow). These are not on the click->collapse-start path; leave them unless measurement says otherwise.
