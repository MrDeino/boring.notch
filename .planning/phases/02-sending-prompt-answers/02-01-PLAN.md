## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | OrchestratorPost.request | mitigate | key allowlist (Enter/Escape/Up/Down/Tab/1-9) and non-empty text checked client-side before any send; server enforces the same |
| T-02-02 | Spoofing | server CSRF guard | mitigate | every POST carries `x-orch: 1` + JSON content type; base URL is loopback, Host set from URL |
| T-02-03 | Tampering | tests | mitigate | tests POST only to the :4799 mock; harness file asserted to contain no `4777` |
| T-02-04 | Tampering | detectPrompt on stale scrollback | mitigate | only prompts ending in the last 4 non-blank lines count, so a scrolled-up prompt cannot produce digit buttons |
| T-02-05 | Information disclosure | loopback HTTP | accept | localhost only, no secrets in bodies |
</threat_model>
